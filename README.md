# 📝 Личный Дневник & Заметки (SaaS)

Современное одностраничное веб-приложение (SPA) для ведения личного дневника с многопользовательской авторизацией, динамическим сайдбаром и изоляцией данных. Построено на стеке **FastAPI** и **FastUI** с использованием **SQLAlchemy 2.0**.

## ✨ Основной функционал
* 🔑 **Полноценная авторизация:** Регистрация, вход и безопасный выход с криптографической подписью сессий (`itsdangerous`).
* ⏳ **Скользящая сессия (Sliding Expiration):** Защита пользователя от внезапного логаута во время написания заметок через Middleware.
* 📂 **Динамический макет:** Полноценный интерфейс сайта с Header, Footer и левым Sidebar.
* 🏷 **Категории:** Возможность создавать собственные папки и привязывать к ним заметки через выпадающие списки (Select).
* 👤 **Ролевая админка:** Панель управления пользователями (`/users`), доступная только для главного администратора с функцией каскадного удаления аккаунтов.
* 📦 **Архив и безопасность:** Полноценная изоляция данных пользователей на уровне SQLite. Возможность архивации и восстановления записей.

## 🛠 Стек технологий
* **Backend:** Python 3.12, FastAPI, Pydantic v2
* **Frontend:** FastUI (Bootstrap 5 под капотом)
* **Database:** SQLite, SQLAlchemy 2.0 (Режим WAL, каскадные связи)
* **Инструменты:** Pathlib, Git, UV (Менеджер пакетов)

## 🚀 Быстрый запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/black40/daily-entries
cd daily-entries
```

### 2. Настройка переменных окружения
Создайте файл `.env` в корневом каталоге проекта:
```text
DIARY_SECRET_KEY=ваш_секретный_ключ_для_подписи_кук
DATABASE_URL=sqlite:///./data/notes_app.db
```

### 3. Автоматический запуск через uv
Утилита `uv` сама создаст окружение и установит все пакеты. Просто выполните команду:
```bash
uv run uvicorn app.main:app --reload
```
Приложение будет доступно по адресу: `http://127.0.0.1:8000`
